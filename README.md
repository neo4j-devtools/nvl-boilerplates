This repository contains boilerplates for creating a new project with NVL using [Webpack](https://webpack.js.org/) and [Vite](https://vitejs.dev/). The available starter templates are organized by folder: [Angular](https://angular.io/) (TypeScript, using Angular CLI), plain JavaScript and [React](https://reactjs.org/) boilerplates with JavaScript/TypeScript and Vite/Webpack variants. Copy the contents of the folder for the starter template you want to use into a new folder and install the dependencies with your preferred package manager, e.g. using `yarn install`.

For further information, visit https://neo4j.com/docs/nvl/current/.
